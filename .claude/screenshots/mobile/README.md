# screenshots/mobile

`mobile/`（icecream_log Flutterアプリ）の動作確認のためにClaudeが撮影する、その場限りのスクリーンショット置き場です。

- Android/iOSシミュレータでの手動検証（`adb exec-out screencap`等）で撮った画像を保存します。
- 画像ファイル（`*.png` / `*.jpg` / `*.jpeg`）はリポジトリ直下の `.gitignore` で除外されており、コミット対象にはなりません。このREADMEのようなドキュメントのみ追跡されます。
- アプリのソース（`mobile/`配下）ではなく `.claude/` 配下に置いているのは、これらの画像がアプリ本体の成果物ではなく、Claudeによる検証作業の副産物だからです。
