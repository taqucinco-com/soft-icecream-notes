# soft-icecream-notes

食べたソフトクリームの写真からメモを作成するアプリ。Claude Codeを利用したエージェントで「開発者自身がコードを作成しない」ための環境づくりをテーマに開発を行う実験的リポジトリ。

## claude

claudeを活用した仕様駆動開発を行う。詳細は [CLAUDE.md](./CLAUDE.md) を参照。

## ドキュメント

- 開発環境のセットアップ、環境変数、E2E実行、AWS運用など、人間の開発者向けの手順は [CONTRIBUTING.md](./CONTRIBUTING.md) を参照
- AIエージェント向けの共通ルールは [AGENTS.md](./AGENTS.md)、Claude Code固有のルールは [CLAUDE.md](./CLAUDE.md) を参照
